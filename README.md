# 🤖 ML Models From Scratch

A hands-on machine learning repository where I implement and understand **Machine Learning algorithms from scratch**, focusing on the mathematical intuition, core logic, and implementation rather than directly relying on pre-built ML models.

The goal of this repository is to build a strong understanding of **how ML algorithms actually work internally**.

---

## 📚 Topics Covered

### 🔹 Supervised Learning

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

### 🔹 Unsupervised Learning / Clustering

- K-Means Clustering
- DBSCAN
- Hierarchical Clustering

### 🔹 Deep Learning

Currently working on:

- ⏳ KNN / Neural Network fundamentals
- ⏳ CNN (Convolutional Neural Network)
